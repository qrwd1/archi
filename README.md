## Фазы ADM и ход разработки архитектуры

### 4. На этапе C TOGAF ADM при замене используемого приложения архитектура данных должна
**Варианты:**
- описывать, как произведенное изменение влияет на другие архитектурные проекты
- быть реорганизована для обеспечения согласованности с технологической архитектурой
- определять требования к миграции данных
- включать требования к совместимости приложений
- оценивать варианты решения любых проблем, связанных с использованием нового приложения
**Ответ:** определять требования к миграции данных
**Объяснение:** Когда существующее приложение заменяется, возникает критическая необходимость в миграции данных (основных, транзакционных и справочных) в новое приложение. Архитектура данных должна определить требования к миграции данных, а также предоставить индикаторы уровня трансформации, отсеивания и очистки, которые потребуются для представления данных в формате, соответствующем требованиям и ограничениям целевого...
**Источники:** База знаний/Миграция данных при замене приложений в TOGAF Phase C

- Обеспечивать достижение целей по доступности услуг
- Производить мониторинг и улучшать эффективность проектирования услуг
- Определять, документировать, согласовывать, производить мониторинг, измерять и выполнять обзор уровней услуг
**Ответ:** Производить мониторинг и улучшать эффективность проектирования услуг
**Объяснение:** Правильный ответ соответствует TOGAF или ITIL и отмечен в исходной заметке как верный вариант.
**Источники:** Координация проектирования
